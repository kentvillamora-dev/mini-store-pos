# Mini Store POS — AI Repository Documentation Pack

Place the `docs` folder in the root of your POS repository.

Recommended repository structure:

```text
mini-store-pos/
├── src/
├── public/
├── package.json
├── README.md
└── docs/
    ├── PROJECT_CONTEXT.md
    ├── ARCHITECTURE.md
    ├── DATABASE.md
    ├── BUSINESS_RULES.md
    └── AI_HANDOFF.md
```

Start every substantial AI coding session by asking the model to read the five files in `docs/` and inspect the relevant implementation before proposing changes.

`AI_HANDOFF.md` is intentionally short and should be updated most often.
